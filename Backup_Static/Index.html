¿Qué es EDU-K?

EDU-K es un sistema web destinado a la administración y gestión de datos en instituciones privadas desde el grado 6° hasta el grado 11°.

Nuestra plataforma te permite tener el control total de tu institución de manera fácil, rápida y segura.
